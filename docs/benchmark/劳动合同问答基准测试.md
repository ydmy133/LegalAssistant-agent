## 2. 评测方法

### 2.1 耗时（Latency）

| 指标 | 定义 |
|------|------|
| **端到端耗时** | 用户点击「发送」→ 流式回答完全结束（含工具调用、首字延迟、全文生成） |
| **记录方式** | 前端气泡下方「耗时」；或 API 压测脚本 |
| **单位** | 秒（s），保留 1 位小数 |
| **多次测试** | 同一配置建议至少 **3 次**；总表填写 **算术平均**，详细记录中列出每次样点 |

**推荐命令（支持多次取平均）：**

```bash
# 第 3 个参数为跑次，默认 1
./scripts/bench-q-labor-001.sh http://127.0.0.1:8080 1 3
```

> 说明：前端气泡耗时与 API `curl` 计时口径略有差异（前端多为首包到结束；API 含建连与整段 SSE）。对比时请固定同一种口径。

### 2.2 准确度（Accuracy）

采用 **百分制（0–100）**，由人工按下列维度打分后取加权平均（可使用下表自评）。

| 维度 | 权重 | 说明 |
|------|------|------|
| 法条正确性 | 30% | 援引法律名称、条款是否准确、无编造 |
| 要点完整性 | 25% | 是否覆盖双倍工资、无固定期限、举证/解除等核心后果 |
| 细节准确度 | 20% | 1 个月宽限期、11 个月上限、满 1 年视为无固定期限等 |
| 判例/来源 | 15% | 是否引用知识库或判例，来源是否相关 |
| 结构与可用性 | 10% | 条理清晰、建议可执行、无明显误导 |

**等级参考：**

- **90–100**：可直接作为法律咨询参考，瑕疵极少  
- **75–89**：主体正确，少量细节缺失或表述不严谨  
- **60–74**：有部分正确内容，但遗漏关键后果或存在误导风险  
- **&lt;60**：法条错误、编造或严重不完整

## 未签劳动合同的法律后果

根据《中华人民共和国劳动合同法》（2008年1月1日施行，2012年修正）的规定，用人单位未与劳动者签订书面劳动合同，将面临以下法律后果：

### 一、支付双倍工资（最核心的后果）

**法律依据：**《劳动合同法》第82条

> 用人单位自用工之日起**超过一个月不满一年**未与劳动者订立书面劳动合同的，应当向劳动者**每月支付二倍的工资**。

具体理解：
- **宽限期**：法律给予用人单位**1个月**的宽限期（自用工之日起算）
- **双倍工资期间**：从第2个月起至满1年止，最长计算**11个月**的双倍工资
- 例如：工作8个月未签合同，可主张第2~8个月共7个月的双倍工资差额

### 二、视为已订立无固定期限劳动合同

**法律依据：**《劳动合同法》第14条

> 用人单位自用工之日起**满一年**不与劳动者订立书面劳动合同的，视为用人单位与劳动者已订立**无固定期限劳动合同**。

这意味着：
- 满1年后不再产生双倍工资
- 但双方之间**自动转为无固定期限劳动合同**，用人单位不得随意解雇
- 解除关系需符合法定情形并支付经济补偿

### 三、劳动者容易确认劳动关系并维权

根据《劳动争议调解仲裁法》，因订立劳动合同发生的争议属于劳动争议，劳动者可以：
- 向劳动仲裁委员会申请仲裁（**仲裁前置**，一般先仲裁后诉讼）
- 注意**仲裁时效为1年**（自知道或应当知道权利被侵害之日起计算，离职后1年内须申请）

### 四、用人单位举证不利

法律实践中，未签劳动合同时，用人单位往往难以证明工资标准、试用期约定、工作年限、考勤记录等；用人单位应妥善保管劳动合同、考勤、工资条等证据，否则承担不利后果。

### 五、典型案例参考

**【(2023)京01民终1234号】北京一中院双倍工资纠纷案**：法院支持劳动者依据第82条主张未签劳动合同期间的双倍工资差额。

### 给用人单位 / 劳动者的建议

入职1个月内签订书面合同；劳动者保留工资流水、考勤、聊天记录等证据；主张双倍工资注意仲裁时效1年。
